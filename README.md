# Maandbudget

Web-app voor het maandbudget van Barry en Ilona: vaste lasten, inkomsten, schulden, spaardoelen en ING-afschriften.

- Inloggen met een Google-account; alleen de twee eigen accounts hebben toegang (afgedwongen door de beveiligingsregels van Firebase).
- Gegevens staan in Firebase (Firestore) en worden live bijgewerkt bij beide gebruikers.
- Afschriften (ING-CSV) kies je zelf uit Google Drive via het kiesvenster in de app.

In deze openbare repository staat alleen de code. Er staan geen budgetgegevens in.

De volledige werking staat in `WERKING.md` in het Claude-project "Maandelijks Budget Bestand".
